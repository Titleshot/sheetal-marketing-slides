## Adding a new slide

1. Create your slide component in `src/components/`
2. Add one entry to **`src/slides/registry.js`** with `id`, `title`, `titleNe`, `section`, and `Component`

The slide appears automatically in navigation, dots, and **Table of Contents**.

## Controls

| Control | Action |
|---------|--------|
| **→** | Scroll down within slide, or next slide at bottom |
| **←** | Scroll up within slide, or previous slide at top |
| **T** | Open / close Table of Contents |
| **Contents** (top-right) | Table of Contents sidebar |
| Bottom-left pill | ← →, slide count, thin progress bar |
| **Presentation toggle** (bottom-right) | Larger text for projector |

## Run

```bash
npm install
npm run dev
```

Open **http://localhost:5173/**

## Design rules

- **One slide = one idea**
- **Layout:** cinematic black card, ~16:9 *width* on large screens; **height grows** with content  
- **Scroll:** the page scrolls naturally when a slide is tall (all screen sizes) — content is never clipped to fit one viewport
- **Manual advance** with arrow keys or on-screen controls
